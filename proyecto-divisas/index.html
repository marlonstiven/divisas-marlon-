Descripción: Aplicación web para convertir entre 20 divisas usando tasas definidas en JavaScript. Soporta validaciones, banderas, formato a 2 decimales, responsive y muestra la fecha/hora de la conversión.

Extras: validación de entrada, copiar resultado al portapapeles (doble click), y ajustes visuales para móvil.
